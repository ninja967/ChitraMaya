02/15

The Fragmented Reality

Current AI filmmaking workflows suffer from catastrophic fragmentation and massive data loss between disconnected tools.

  • Context Loss: Moving from a LoRA trainer to an Image Generator strips away scene context.
  • Manual Routing: Creators must manually copy-paste seed numbers to maintain temporal consistency.
  • Resource Waste: Blindly generating text-to-video wastes immense GPU cycles on bad compositions.
03/15

The Agent-Native Architecture

ChitraMaya replaces manual routing with an autonomous FastAPI Control Plane.

// THE AGENTIC LOOP
1. User inputs unstructured intent ("Make a sci-fi scene").
2. FastAPI Agent parses intent into structured Project Metadata.
3. Agent dispatches perfectly formatted ComfyUI Prompt JSON to GPU.
4. GPU returns blob; Agent catalogs asset into PostgreSQL.
5. Human reviews.

The Agent Dashboard

The UI is completely abstracted from the underlying node graphs.

The Project Pipeline Concept

Professional rendering requires strict metadata enforcement.

07/15

Pipeline Execution

The "Alchemist Lab" pipeline view provides a complete audit trail.

The PostgreSQL backend tracks state transitions. Jobs move from DRAFT → QUEUED → RENDERING → REVIEW. The time elapsed is calculated on the server to prevent client-side desync.

08/15

The Scene Builder

Deconstructing the script into executable GPU threads.

Each shot card represents a separate generation request. The backend calculates the optimal batch size based on available VRAM, executing multiple independent shots in parallel if resources allow.

09/15

FLUX.1 to Wan 2.1 Pipeline

Direct Text-to-Video is computationally wasteful. We enforce Image-to-Video routing.

// COMPUTE SAVINGS ANALYSIS
Bad Video Render: 100% GPU load for 3 mins -> Trash.
Image Render (FLUX): 100% GPU load for 8 seconds -> Human Approves.
Video Render (Wan2.1): 100% GPU load for 3 mins -> Guaranteed Perfect Framing.

=> Compute Waste reduced by ~95%.
10/15

Identity LoRA Tuning

Running ai-toolkit directly on the AMD cluster.

The backend accepts a `.zip` of 10-20 images, extracts them, injects the trigger word into the configuration YAML, and spawns a background training process using ROCm. The resulting `.safetensors` file is instantly mounted to the inference pipeline.

The Proxy Bridge Architecture

Seamlessly connecting public UIs to private GPU clusters.

  • Hugging Face Space Hosts the React/Vite Frontend.
  • Node.js Express Proxy Sits on Hugging Face, intercepting API calls and forwarding them to the hidden Droplet IP.
  • Server-Sent Events (SSE) Maintains an open connection to stream live generation progress (e.g., "55% rendered") back to the user's browser with `< 50ms` latency.
