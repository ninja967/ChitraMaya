The Agent-Native Cinematic Engine

An autonomous film studio orchestrated by AI,

The Problem

Right now, creating a cohesive AI video requires jumping between a dozen disjointed tools. You train a LoRA here, generate images there, and prompt video in a Discord bot.

The Analogy: It’s like trying to direct a blockbuster movie, but your actors, cameras, and set designers are all on different continents and don't speak the same language.

The "Agent-Director"

ChitraMaya is not just a UI. It is an Agent-Native control plane.

We built a single studio environment where an autonomous AI Agent orchestrates the entire production pipeline. You give the Agent a script; it directs the tools.

The "Pocket Rulebook"

The AI Agent doesn't guess how to make a video. It reads our strict FastAPI OpenAPI specs, understands the MI300X pipeline, and seamlessly dispatches complex multi-shot jobs.

Infrastructure

The AMD Advantage

To run an entire film studio locally, you need a very big lot.

  • 192GB VRAM: No OOM errors. We run FLUX.2, LLMs, and Wan 2.2 simultaneously.
  • ROCm 6.x: Flawless native PyTorch compute without relying on CUDA.
  • Instant Context Switching: The agent leaps from image to video generation without unloading models.

The Stack

Compute: AMD MI300X

API: FastAPI / Python

Engines: ComfyUI, ai-toolkit

UI: React 18, Vite

Track 2: Fine-Tuning

Custom Identity LoRAs via ROCm

We built a native training wizard directly into the dashboard.

  • Upload a .zip dataset of your actor or character.
  • The backend dispatches an ai-toolkit job directly to the AMD MI300X.
  • Trains a high-fidelity FLUX.2 LoRA in roughly 90 minutes.
  • The Agent immediately knows how to inject this LoRA into your video pipelines.

Hugging Face Integration

While the heavy lifting happens on the AMD bare metal, the user experience lives smoothly in the cloud.

The Bridge: We use a Dockerized Hugging Face Space to host our React frontend. A secure websocket proxy bridges the user's browser directly to the remote MI300X server, streaming live generation progress.

Business & Scalability

Business Model

  • B2B Enterprise: Licensing the agentic backend to creative studios running private AMD hardware.
  • Cloud SaaS: Tiered subscriptions for indie filmmakers on Hugging Face Spaces.
  • Marketplace: A hub to buy/sell custom LoRAs.

Future Scale

  • Distributed Rendering: Scaling FastAPI to dispatch jobs across multi-node MI300X clusters.
  • Audio Agents: Integrating AudioCraft for automatic foley and sound effects.
  • Real-time Canvas: Moving from async queues to real-time interactivity.
